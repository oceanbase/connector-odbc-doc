# OceanBase Connector/ODBC V2.0.7

## Version information

* Release date: February 27, 2023
* Version: V2.0.7

## Overview

The latest version of the ODBC V2.0 series has been released to support customer project launches and proof-of-concept (POC) usage for customers with new requirements.

## Feature enhancements

* Added support for the REF CURSOR data type in Oracle-compatible mode. For more information, see [Query data of a REF CURSOR cursor](../../300.user-guide/300.get-cursor-type.md).
* Added a limit on log file size, splitting large log files into multiple smaller ones. For more information, see [Enable logging](../../300.user-guide/200.turn-on-log.md).

## Bug fixes

* Fixed the issue where data synchronization via ODBC was slow when using Informatica.
* Fixed the issue where the result returned by calling SQLGetInfo was incorrect in MySQL-compatible mode tenants.
* Fixed the issue where the Scale specified for `SQL_NUMERIC_STRUCT` was invalid for the corresponding parameter in SQLBindParameter in Oracle-compatible mode.
* Fixed the issue where the number of digits obtained for FLOAT/BINARY_FLOAT/BINARY_DOUBLE was incorrect using `SQLColAttribute` and `SQL_DESC_PRECISION`.
* Fixed the issue in C# where a parsing error occurred because there was a space between the curly braces in `{ CALL xxx(?,?)}`.
* Fixed the issue where the result of `SQLGetTypeInfo(Stmt, SQL_ALL_TYPES)` in Oracle-compatible mode was inconsistent with Oracle's.
* Fixed the issue where data copying failed using `SQLCopyDesc`.
* Fixed the issue where the `FK_NAME` field was missing in the `SQLForeignKeys` ODBC call.
* Fixed the issue where obtaining columns for a stored procedure containing `PACKAGE` failed using `SQLProcedureColumns`.
* Fixed the issue where obtaining PLs containing `PACKAGE` failed using `SQLProcedures`.
* Fixed the issue where the ISQL tool behaved abnormally on 32-bit or ARM systems.
