# OceanBase Connector/ODBC V2.0.8

## Version information

* Release date: April 12, 2023
* Version number: V2.0.8

## Overview

The latest version of the ODBC V2.0 series has been released, adding support for the escape functionality of three scalar functions: `IFNULL`, `SUBSTRING`, and `LEFT`. This version is recommended for regular business use.

## Feature enhancements

* In Oracle-compatible mode, added support for the escape functionality of three scalar functions: `IFNULL`, `SUBSTRING`, and `LEFT`. For more information, see [Scalar function escape functionality](../../300.user-guide/400.scalar_function.md).
* In Oracle-compatible mode, added support for the Call Function feature. For more information, see [Call Function](../../300.user-guide/500.call_function.md).

## Bug fixes

* Fixed an issue where single quotes in data were incorrectly recognized when `no_ssps` was enabled.
* Fixed an issue where OceanBase Connector/ODBC returned incorrect lengths when reading certain Chinese characters.
* Fixed an issue in text protocol where using the `SQLBulkOperations` function for batch inserts resulted in a `Memory allocation error`.
* Fixed an issue in text protocol where using `SQLBindCol` to bind result columns greater than 2 caused an `Invalid descriptor index` error.
