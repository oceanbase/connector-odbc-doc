# OceanBase Connector/ODBC V2.0.8

## Version information

* Release date: April 12, 2023
* Version: V2.0.8

## Version description

This version is the latest in the ODBC V2.0 series. It supports the escape of three scalar functions: `IFNULL`, `SUBSTRING`, and `LEFT`. It is recommended for general business use.

## Feature enhancements

* In Oracle mode, the escape of three scalar functions: `IFNULL`, `SUBSTRING`, and `LEFT` is supported. For more information, see [Scalar function escape](../../300.user-guide/400.scalar_function.md).
* In Oracle mode, the Call Function feature is supported. For more information, see [Call Function](../../300.user-guide/500.call_function.md).

## Bug fixes

* Fixed an issue where single quotes in data are incorrectly identified when `no_ssps` is enabled.
* Fixed an issue where OceanBase Connector/ODBC returns an incorrect length when reading certain Chinese characters.
* Fixed an issue where the `Memory allocation error` error occurs when using the `SQLBulkOperations` function to perform a batch insert in text protocol.
* Fixed an issue where the `Invalid descriptor index` error occurs when using `SQLBindCol` to bind result columns greater than 2 in text protocol.
