# OceanBase Connector/ODBC V2.0.6

## Version information

* Release date: October 19, 2022

* Version: V2.0.6

## Overview

The latest version of the ODBC V2.0 series has been released to support customer project implementations and proof-of-concept (POC) usage for customers with new requirements.

## Bug fixes

* Fixed an issue where output parameters were garbled when calling stored procedures in C# in Oracle-compatible mode.
* Fixed an error when reading Number data using Delphi 7 in Oracle-compatible mode.
* Fixed an error when reading Number data using the `go` language via ODBC in Oracle-compatible mode.
