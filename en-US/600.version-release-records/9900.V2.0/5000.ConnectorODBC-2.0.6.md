# OceanBase Connector/ODBC V2.0.6

## Version information

* Release date: October 19, 2022

* Version: V2.0.6

## Version description

This version is released to support the application launch of customer projects and the POC of customers with new requirements.

## Bug fixes

* Fixed the issue where the output parameters of stored procedures are garbled when called from C# in Oracle mode.
* Fixed the issue where an error occurs when reading Number data from Delphi7 in Oracle mode.
* Fixed the issue where an error occurs when using the `go` language to read Number data through ODBC in Oracle mode.
